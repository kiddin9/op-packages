## 更新内容

- 修复子域名反向代理规则的 WebSocket 开关未生效问题。
- 子域名规则现在会正确把 LuCI 中的「WS」配置传入 Nginx 站点生成逻辑。
- 修复后，Open-Box 等依赖 WebSocket 的动态连接、日志、内存和流量页面可通过 MiniGate 外网穿透正常建立动态通道。

## 验证

- `root/usr/lib/minigate/proxy.sh` 语法检查通过。
- 已在软路由实机验证：开启 `box` 子域规则 WebSocket 后，生成的 Nginx 站点配置包含 `Upgrade` 与 `Connection "upgrade"`。
- 普通公网 API 返回 200，未登录 WebSocket 请求返回 401，确认请求已进入上游认证层而非被反代层返回 404。
