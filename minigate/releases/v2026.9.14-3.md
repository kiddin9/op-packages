## 更新内容

- 新增适合 SSH 登录软路由后直接执行的短安装命令：

  ```sh
  curl -fsSL https://raw.githubusercontent.com/tpxcer/minigate/main/scripts/install.sh | sh
  ```

- 在线安装脚本自动获取 GitHub latest Release，不需要手工填写版本号或源码包文件名。
- 安装前后分别获取 `SHA256SUMS`，避免下载过程中恰好切换版本而混用文件。
- 安装前验证源码包 SHA-256、压缩包路径和三处版本信息，通过后才调用正式安装器。
- 保留 README 中的固定版本安装方式，便于指定版本和手工复核。
