## 更新内容

- 项目名称和 OpenWrt 内部包名统一为 `minigate`，GitHub 仓库改为 `tpxcer/minigate`。
- 版本号按北京时间（Asia/Shanghai）发布日期命名：首版为 `2026.9.14`，同日后续版本依次为 `2026.9.14-1`、`2026.9.14-2`。
- 登录 LuCI 后打开 minigate 总览，自动检查 GitHub 最新正式版。自动检查只提示，不下载或安装；10 分钟内复用成功检查结果，手动检查不受此限制。
- 点击「一键更新」先显示本次 Release 的更新内容，点击「确认更新」才安装。期间若最新版本改变，会要求重新查看并确认。
- 更新说明弹窗跟随深浅主题，支持滚动长说明、键盘切换、Esc 关闭和取消。
- 修复更新成功状态可能导致页面反复刷新的问题；保留 SHA-256 校验、配置备份、服务验证与失败回滚。

## 安装与兼容性

- opkg 安装包：`minigate_2026.9.14_all.ipk`。
- 源码安装包：`minigate-v2026.9.14-src.tar.gz`，适用于依赖和固件匹配的 opkg / apk 系统。
- 为兼容 `v1.3.11` 的更新器，本次另附内容相同的 `luci-app-minigate-v2026.9.14-src.tar.gz`。旧名称只用于兼容，不是新内部包名。
- `v1.3.11` 用户升级到本版后，才具备自动检查和更新说明弹窗；旧版不能识别带 `-N` 后缀的日期版，建议先升级本版，或按 README 手动安装。
- 源码/网页更新不修改包管理器数据库。原来通过旧名 IPK/APK 安装的用户，请按 README 先备份并迁移包名，不要混用两种包名。
- 本次仅发布 GitHub 更新，不自动安装到任何软路由。
