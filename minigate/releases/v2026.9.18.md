## 更新内容

- 动态 DNS 页面新增「最近一天 IP 变化明细」。
- 按 DDNS 记录分别展示 IPv4 / IPv6 地址、开始时间、结束时间和持续时长。
- 当前仍在使用的 IP 标记为「使用中」，支持筛选单条 DDNS 记录和手动刷新。
- 桌面端使用紧凑表格，手机端改为纵向明细，优先显示 IP 地址和持续时间。
- 修复源码安装漏装 `openssl-util`，导致 ACME 签发和续期缺少 OpenSSL CLI 的问题。

## 存储与性能

- 历史保存在 `/etc/minigate/ddns-history`，每条记录文件权限为 `0600`。
- 只有检测到 IP 真正变化时才写入，稳定轮询不会触碰历史文件。
- 保留最近 24 小时事件和窗口前最后一条锚点，可正确计算跨越查询边界的持续区间。
- 普通卸载继续保留历史数据；只有主动选择彻底清理时才会删除。
