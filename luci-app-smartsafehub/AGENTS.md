# AGENTS.md

## 기본 작업 원칙

- 첨부된 최신 소스 코드를 기준으로 작업한다.
- 기존 기능 및 보안 정책을 유지한다.
- 요청 범위를 벗어나는 리팩토링을 하지 않는다.
- 프런트엔드 빌드 결과물을 생성하거나 패치에 포함하지 않는다.
- Python 문법 오류는 별도 요청이 없는 한 수정하지 않는다.

## 패치 작성 규칙

- 일반 패치는 revision을 증가시킨다.
- 보강 패치는 revision과 CHANGELOG.md를 변경하지 않는다.
- CHANGELOG.md는 일반 사용자가 이해하기 쉽게 작성한다.
- CHANGELOG 블록 끝에는 빈 줄을 추가한다.
- 패치 파일명은 짧게 유지한다.
- Git commit message를 함께 제공한다.
- 삭제해야 하는 파일이 있다면 명시한다.
- 원본 소스에서 git apply --check를 수행한다.

## OpenWrt 호환성

- OpenWrt 및 BusyBox 환경과의 호환성을 유지한다.
- GNU 전용 명령어와 옵션을 사용하지 않는다.
- APK 패키지 관리 방식을 준수한다.
- 저사양 공유기의 CPU, 메모리 및 저장 공간을 고려한다.

## Apps 관리 정책

- 승인된 패키지만 설치 및 업데이트한다.
- 패키지 서명 및 SHA256 검증을 유지한다.
- 실제 설치 버전과 Apps 관리 기록을 구분한다.
- Apps에서 설치한 앱은 수동 업데이트 이후에도 업데이트 및 제거가 가능해야 한다.
- 처음부터 수동 설치한 앱은 자동으로 Apps 관리 대상에 편입하지 않는다.
- APK identity pin을 고려한다.
- 다른 앱의 패키지, 공용 의존성 및 시스템 패키지를 보호한다.
- 작업 실패 시 기존 관리 기록을 보존한다.

## 테스트 규칙

- 기능 변경 시 반드시 회귀 방지 테스트를 추가한다.
- 변경된 함수를 호출하는 모든 테스트를 확인한다.
- 독립적으로 함수를 추출하는 테스트의 의존성도 확인한다.
- 정상 동작뿐 아니라 실패 및 복구 시나리오도 검증한다.
- 가능한 경우 전체 ShellSpec 테스트를 실행한다.
- 실행하지 못한 테스트는 결과 보고 시 명시한다.

## 작업 완료 조건

- 요청 사항 구현
- 기존 기능 및 보안 정책 유지
- 관련 테스트 통과
- 패치 적용 검증
- revision 및 CHANGELOG 확인
- 다운로드 가능한 패치 제공
