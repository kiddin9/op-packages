# 更新日志

## 26.11.12-r1 — 2026-11-12

### 配置与运行时

- 将代理和分流核心 JSON 的生成、校验迁移到 ucode。前端负责编辑、预览和提交，后端根据配置生成数据；Shell 负责服务、路由、防火墙加载及定时任务等系统操作。
- 将 ucode 类型声明集中到专用文件，清理已不用的配置生成代码和运行入口，减少查询结果通过临时文件中转。
- 本地服务器改为按核心与协议生成配置，支持 shadowsocks、hysteria2、vless，并按核心能力提供传输和 TLS/REALITY 选项。
- 补充 DNS 依赖代理的预检；调整 procd 实例提交与路由、防火墙等辅助阶段的执行顺序及错误日志。

### 编辑与诊断

- 文件编辑改为与 RPC session 关联的浏览器草稿：保存时保留草稿，应用时才写入后端文件；增加待应用文件入口、差异预览和恢复操作。
- 文件草稿恢复直接更新编辑器，保留其他表单输入和 UCI 待应用变更，不再触发整页重载。
- 统一代理与服务端配置预览，补充字段提示、配置编辑器语法高亮、服务端节点日志查看和 Shadowsocks 2022 随机密钥生成。
- 下载页面刷新后恢复任务状态和进度；更新失败时停止后续替换或重启步骤，并通过锁避免重复更新。
- 完善服务与更新日志，明确防火墙重载来源和规则归属；第三方正常输出降至 DEBUG，移除日志中的任务编号。
- 路由诊断按依赖检测结果显示 tcpdump 选项，兼容不支持小数 sleep 的 BusyBox，并处理服务启动时的旧任务与诊断数据。

### 防火墙与请求处理

- 对确认由 hijpass 接管的透明代理连接增加全局 SYN 限速豁免，保留后续访问控制；随 fw4 加载检查并维护规则，避免重复和残留。
- 文件编辑 CGI 使用非阻塞读取，连续 5 秒没有收到请求体数据时退出，避免中断上传长期占用 uhttpd 的共享 CGI 名额。持续上传可超过 5 秒；该措施是应用层超时兜底，不包含 uhttpd 本身的断开处理修复。

### 升级注意

- 旧 Shell 防火墙模板与新 ucode 模板不兼容。保留旧模板并提示手动迁移自定义内容，不自动覆盖。
- 旧版自定义服务端节点保留配置并停用，需要转换为新版协议字段后再启用。
