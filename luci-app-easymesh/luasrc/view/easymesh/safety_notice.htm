<%:Safety%>

⚠️ <%:Avoid these characters in SSIDs/passwords:%> " ' ` $ \ | <%:— plus newlines and em/en dashes:%> (—, –). <%:They break this shell-based app's sync.%>
<%:Click for full safety rules%>
<%:✅ Do%>
  • <%:Use only letters, numbers, hyphens, and underscores in SSIDs.%>
  • <%:Keep SSIDs 32 characters or fewer.%>
  • <%:Use ASCII characters if SSID sync is enabled.%>
  • <%:Back up config before every change.%>
  • <%:Test one client node at a time when changing settings.%>
<%:❌ Don't%>
  • <%:Never use quotes, backticks, dollar signs, or backslashes in SSIDs/passwords.%>
  • <%:Never change SSID while client nodes are offline.%>
  • <%:Never edit a synced node's SSID manually.%>
  • <%:Never run luci-app-easymesh alongside meshd (OMM).%>
  • <%:Never set sync interval below 10 seconds.%>
<%:Field-by-field safety reference%>
<%:Field%><%:Safe%><%:Unsafe%>
<%:Mesh ID%> A-Z a-z 0-9 _ - " ' ` $ \ |
<%:Password%> A-Z a-z 0-9 ! @ # % ^ & * _ - + = " ' ` $ \ | + newline
<%:SSID%> A-Z a-z 0-9 _ - space " ' ` $ \ |
<%:VLAN IDs%> 0-9 , <%:everything else%>
<%:Why these limits? A compiled daemon like meshd (6 MB) never passes user input through a shell. Lua and shell scripts necessarily do — the sync protocol uses nc, openssl, and uci as external commands.%>
