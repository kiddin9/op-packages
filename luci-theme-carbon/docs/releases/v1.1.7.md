## English

### What's new

- **Device traffic source.** The overview uses `nlbwmon` by default and never probes nftables in that mode. To sample named nftables counters every five seconds, select **nftables** under **System → Carbon Theme Settings**. If the selected source is unavailable, the device list stays visible.
- **Container memory reporting.** The dashboard reads memory and swap figures from `/proc/meminfo` so it can show consistent totals on LXC systems using lxcfs.
- **Open-Box channel selection.** The selected radio button indicator stays inside its control instead of covering the page.

### Upgrade notes

- Existing `nlbwmon` users can keep their settings. To use nftables, configure a named upload/download counter pair for each device in `inet carbon_acct`. If your rules use anonymous `counter` statements, replace them with references to the named counters before selecting nftables. [Setup and migration guide](https://github.com/mrjoechen/luci-theme-carbon/blob/v1.1.7/docs/device-traffic.md#english)
- If LuCI denies the counter query after upgrading, restart rpcd and log in again.

## 简体中文

### 更新内容

- **设备网速来源。** 概览默认使用 `nlbwmon`，此模式不会探测 nftables。要每 5 秒采样一次 nftables 命名计数器，请在 **系统 → Carbon 主题** 中选择 **nftables**。所选来源不可用时仍保留设备列表。
- **容器内存统计。** 仪表盘从 `/proc/meminfo` 读取内存和交换空间数据，使使用 lxcfs 的 LXC 系统能显示口径一致的数值。
- **Open-Box 频道选择。** 修复选项被选中时单选标记覆盖整个页面的问题。

### 升级须知

- 继续使用 `nlbwmon` 无需更改设置。要使用 nftables，请在 `inet carbon_acct` 表中为每台设备配置一对上下行命名计数器。如果现有规则使用匿名 `counter`，请先改为引用对应的命名计数器，再选择 nftables。[配置与迁移指南](https://github.com/mrjoechen/luci-theme-carbon/blob/v1.1.7/docs/device-traffic.md#中文)
- 升级后若 LuCI 拒绝读取计数器，请重启 rpcd 并重新登录。
