## English

### What's new

- **Customizable dashboard layout.** Click **Customize** under *Status → Overview* to choose presets (*Default*, *Home Wi-Fi*, *Multi-WAN*), toggle panels, add up to four independent Live Traffic charts (for any interface or physical port), enable Wi‑Fi and Temperature stat tiles, and reorder sections with live preview and a collapsible preview dock. The default layout places *Discovered devices* on its own full-width row above side-by-side *Wireless* and *Interfaces* cards. Layouts are persisted in `/etc/config/carbon` via UCI across browsers and upgrades, hidden panels stop polling, and a reset option is available in **System → Carbon Theme Settings**. (#12)
- **Control alignment and table action buttons.** Fix vertical alignment and spacing for `.control-group` and inline input/button controls across Package Manager, Network Diagnostics, password reveal fields, dynamic lists, and the file browser on desktop and phone. Keep direct-child buttons in `.td.cbi-section-actions` (such as Package Manager *Install…* and DHCP *Set Static*) compact and centred instead of stretched across the cell. (#13)
- **Lease table and device avatars.** Detect the IP address column at the table level with strict IPv4/IPv6 matching so rows whose hostname falls back to an IP address keep their avatar in the hostname column rather than a preceding status or interface column. Ignore placeholder (`-`, `*`, `?`) and IP-only hostnames consistently across lease tables and the dashboard. (#13)

### Upgrade notes

- After upgrading, log out of LuCI and back in once (or restart `rpcd` and log in again) so the new `set_dashboard` RPC permission for saving custom dashboard layouts takes effect.

## 简体中文

### 更新内容

- **自定义仪表盘布局。** 在「状态 → 概览」底部点击 **自定义**，可切换预设（默认、家用无线、多口监控）、开关各模块、添加最多 4 个独立的实时流量监控卡片（可选任意接口或物理网口）、启用 Wi‑Fi 与温度磁贴并调整区块顺序，支持实时预览与折叠预览浮条。默认布局将「已发现设备」独立占满整行，下方并排展示无线与网络接口；配置通过 UCI 保存在 `/etc/config/carbon` 中跨设备与升级保留，隐藏模块自动停止轮询，并可在「系统 → Carbon 主题」一键重置。（#12）
- **表单控件组对齐与表格操作按钮。** 修复软件包页筛选/安装栏、网络诊断、密码显示框、动态列表与文件浏览器中输入框与按钮在桌面端和手机端的垂直错位与间距问题；修复表格操作列 `.td.cbi-section-actions` 内直接子按钮（如软件包页「安装...」、DHCP「设为静态」）被拉宽且文字靠右的问题。（#13）
- **租约表与设备列表头像。** 改为按整张表识别 IP 列并严格区分 IPv4/IPv6 与 MAC 地址，修复主机名为 IP 地址时设备图标错位到前置状态圆点列或接口列的问题；在租约表与仪表盘中统一过滤 `-`、`*`、`?` 及纯 IP 占位主机名。（#13）

### 升级须知

- 升级后请退出 LuCI 并重新登录一次（或重启 `rpcd` 后重新登录），让保存自定义仪表盘布局所需的 `set_dashboard` RPC 权限生效。
