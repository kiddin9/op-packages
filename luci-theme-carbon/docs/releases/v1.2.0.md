## English

### What's new

- **Customizable Simple menu with drag-to-reorder.** Open the glass slide-over customizer from the Simple sidebar or **System → Carbon Theme Settings** to add any installed LuCI page or plugin, remove unwanted defaults, search available pages, or restore the default menu in one click. Reorder items within and across *Common* and *System* groups via drag handles in the customizer (with smooth FLIP animations, edge auto-scroll, and `Escape` cancel) or by clicking and holding (~280 ms) directly in the Simple sidebar. Custom menus are persisted in `/etc/config/carbon` via UCI across devices and upgrades, handle `opkg`/Package Manager aliases and uninstalled entries gracefully, and fall back to `localStorage` in the static preview. (#19)
- **Clearer dashboard load average and per-SSID wireless details.** Replace the raw three-number load average in the *Resources* card with the 1-minute value, a CPU-core-normalized status badge (*Normal* / *Busy* / *High*), and a shared 1/5/15-minute tooltip. Display total Wi-Fi client count, colored frequency-band badges, channel width (including `HT40+`/`HT40-`/`VHT80+80`), encryption, and deduplicated per-SSID client counts in the *Wireless* card and *Wi-Fi* stat tile, with unified Chinese `Wi-Fi` labels and updated translations across all 12 i18n catalogues.
- **Fix false "No wireless" status.** Prefer `luci-rpc` `getWirelessDevices` (with fallback to `network.wireless` `status`) and pass `reject: true` on wireless, `assoclist`, and layout/menu RPC calls so ubus errors are not coerced into empty objects. Handle UCI string `disabled='0'`/`'1'` flags, fall back to runtime `iwinfo` frequency/channel/SSID/encryption for drivers such as `brcmfmac` (e.g., Phicomm N1), refine `hwmode` and AP mode matching (`ap-wds`, `Master (VLAN)`), and show *Off* or *Unavailable* instead of *No wireless* when radios exist or RPCs fail. (#15)
- **Unified button variants across `<input>` and `<button>` controls.** Wrap `submit`/`button`/`reset` input selectors in `:where()` so single-class LuCI variants (`.cbi-button-remove`, `.cbi-button-add`, `.cbi-button-edit`, `.cbi-button-reset`, etc.) render consistently on classic CBI and plugin `<input>` buttons (such as PassWall) as well as `<button>` elements. Introduce `--cb-btn-bg`, `--cb-danger`, and `--cb-danger-strong` tokens to fix dark-mode specificity collisions and solid danger hover colors, align destructive/reset/positive controls with LuCI conventions, and exclude button inputs from text `input:focus` rings. (#17)

### Upgrade notes

- After upgrading from v1.1.9 or earlier, log out of LuCI and back in once (or restart `rpcd` and log in again) so the new `set_simple_menu` and `getWirelessDevices` RPC permissions take effect.

## 简体中文

### 更新内容

- **自定义简洁菜单与拖拽排序。** 在简洁侧栏或「系统 → Carbon 主题」中打开毛玻璃抽屉，可搜索并添加任意已安装的 LuCI 页面或插件、移除不需要的默认项，或一键恢复默认菜单。支持在自定义抽屉内拖动排序把手（带平滑 FLIP 动画、边缘自动滚动与 `Escape` 取消），跨「常用」与「系统」分组调整顺序；也支持在简洁侧栏中直接长按（约 280 ms）拖拽排序。配置通过 UCI 保存在 `/etc/config/carbon` 中，跨设备与升级保留，兼容 `opkg`/软件包别名及已卸载条目，静态预览自动回退至 `localStorage`。（#19）
- **概览负载提示与分 SSID 无线详情。** 「资源」卡片改为展示 1 分钟负载值、结合 CPU 核心数归一化的状态徽章（正常 / 繁忙 / 高负载）以及与负载磁贴共享的 1 / 5 / 15 分钟悬停提示。「无线」卡片与 Wi-Fi 统计磁贴展示无线客户端总数、彩色频段徽章、频宽（含 `HT40+`/`HT40-`/`VHT80+80`）、加密方式与去重后的单 SSID 在线设备数；同时将中文无线标签统一为 `Wi-Fi` 并同步更新全部 12 种语言包。
- **修复「未检测到无线网卡」误报。** 优先调用 `luci-rpc` 的 `getWirelessDevices`（失败时回退至 `network.wireless` `status`），并在无线、客户端列表与布局/菜单 RPC 中启用 `reject: true`，避免 ubus 错误被静默转为 `{}`/`[]`。兼容 UCI 字符串形式的 `disabled='0'`/`'1'`，针对 `brcmfmac`（如斐讯 N1）等驱动回退读取 `iwinfo` 运行时频段、信道、SSID 与加密信息，完善 `hwmode` 与 AP 模式匹配（`ap-wds`、`Master (VLAN)`），并在存在无线设备或 RPC 失败时准确显示「已关闭」或「不可用」而非「未检测到无线网卡」。（#15）
- **统一 `<input>` 与 `<button>` 按钮变体样式。** 将 `submit`/`button`/`reset` 输入框基础选择器包裹进 `:where()`，使单类名 LuCI 变体（`.cbi-button-remove`、`.cbi-button-add`、`.cbi-button-edit`、`.cbi-button-reset` 等）在传统 CBI 与插件（如 PassWall）的 `<input>` 按钮和 `<button>` 元素上表现一致。新增 `--cb-btn-bg`、`--cb-danger`、`--cb-danger-strong` 语义变量消除深色模式优先级冲突与危险按钮悬停变蓝问题，对齐 LuCI 危险/重置/正向按钮规范，并排除按钮类 `<input>` 误触文本输入框聚焦样式。（#17）

### 升级须知

- 从 v1.1.9 或更早版本升级后，请退出 LuCI 并重新登录一次（或重启 `rpcd` 后重新登录），让保存自定义简洁菜单所需的 `set_simple_menu` 以及 `getWirelessDevices` RPC 权限生效。
