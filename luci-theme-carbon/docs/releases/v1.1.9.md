## English

### What's new

- **GitHub Pages fallback for online updates.** Keep `api.github.com` and GitHub Releases as the primary sources, and automatically fall back to the official GitHub Pages staged release manifest (`updates/latest.json`) and packages (`updates/<tag>/`) when GitHub is rate-limited, unreachable, times out (including stalled transfers), or returns invalid metadata or checksums. When a download mirror is configured, downloads follow mirror → GitHub Releases → GitHub Pages with the same size, SHA-256, and APK signature checks. Also fixes a lock-ordering race when reading updater status.
- **OpenWrt 23.05 online updater and installer support.** Fall back to a HUP-immune subshell when stock OpenWrt 23.05 BusyBox omits `setsid`, and accept/normalise 23.05 SDK `opkg` revisions without the `-r` prefix (such as `1.1.8-1`) across `luci.carbon_update`, **System → Carbon Theme Settings**, and `carbon-install.sh` so OpenWrt 23.05 installs check and upgrade cleanly to official `-rN` releases.
- **Temperature sensor deduplication.** Skip `thermal`-to-`hwmon` virtual bridges (`/virtual/thermal/`) when thermal zones are present (retaining them as a fallback if `/sys/class/thermal` is unreadable), normalise trailing `-thermal` suffixes, suppress duplicate `scpi_sensors` and `scmi_sensors` hwmon readings when a CPU/SoC thermal zone exists (such as on Phicomm N1 / Amlogic S905D), and prefer `coretemp` over `x86_pkg_temp` on Intel x86 while preserving Wi‑Fi, NVMe, and AMD sensors. (#6)
- **Redesigned Carbon logo.** Refresh the default Carbon emblem with a layered glass hexagon design and align sidebar and login icon corner radii (`border-radius: 25%`) with the SVG geometry.
- **Sidebar plugin icons.** Add semantic sidebar icon mappings for FlowCone, HONK, and irqbalance. (#16)

### Upgrade notes

- Upgrading from v1.1.8 adds no new RPC permissions—just reload the page after upgrading.
- On OpenWrt 23.05 routers running v1.1.8 or earlier (without `setsid` or built with a 23.05 SDK `-1` version), install v1.1.9 once via `carbon-install.sh` or `.ipk` to enable online updates going forward.

## 简体中文

### 更新内容

- **在线升级支持 GitHub Pages 回退。** 继续优先从 `api.github.com` 检查更新并从 GitHub Releases 下载安装包；当 GitHub 受限、不可达、超时（含传输卡死）或返回异常元数据/校验不匹配时，自动回退到项目官方 GitHub Pages 托管的发布清单（`updates/latest.json`）与安装包（`updates/<tag>/`）。配置下载镜像时按「镜像 → GitHub Releases → GitHub Pages」顺序尝试，并保持相同的文件大小、SHA-256 与 APK 签名校验；同时修复状态读取中的加锁顺序竞态问题。
- **OpenWrt 23.05 在线升级与安装脚本适配。** 在默认不含 `setsid` 的 OpenWrt 23.05 BusyBox 环境下回退到忽略 HUP 信号的后台子进程；在线更新器、「系统 → Carbon 主题」页面与 `carbon-install.sh` 均可识别并规范化 23.05 SDK 构建的无 `-r` 前缀版本号（如 `1.1.8-1`），顺利检查并在线升级至正式 `-rN` 版本。
- **温度传感器去重。** 当系统存在 thermal zone 时跳过 `/virtual/thermal/` 虚拟桥接 hwmon（若 `/sys/class/thermal` 不可读仍保留回退），统一归并末尾 `-thermal` 后缀；存在 CPU/SoC 热区时抑制重复的 `scpi_sensors` / `scmi_sensors` 读数（修复斐讯 N1 / Amlogic S905D 等设备温度重复问题）；Intel x86 平台优先显示 `coretemp` 而非 `x86_pkg_temp`，同时保留 Wi‑Fi、NVMe 与 AMD 传感器。（#6）
- **全新 Carbon 图标设计。** 默认 Logo 更新为多层玻璃质感六边形徽标，并统一侧栏、登录页与 SVG 图标的圆角比例（`border-radius: 25%`）。
- **侧栏插件图标补充。** 为 FlowCone、HONK 与 irqbalance 补充侧栏语义图标映射。（#16）

### 升级须知

- 从 v1.1.8 升级未新增 RPC 权限，无需退出重新登录，升级完成后刷新页面即可。
- 若 OpenWrt 23.05 设备当前运行 v1.1.8 或更早版本（缺少 `setsid` 或使用 23.05 SDK `-1` 版本号），请先通过 `carbon-install.sh` 或 `.ipk` 手动升级一次至 v1.1.9，之后即可正常使用网页在线升级。
