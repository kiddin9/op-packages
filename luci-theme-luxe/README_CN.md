**Luci-Theme-LuxeOs** 是一款适用于 OpenWrt 的现代 HTML5 主题，支持 **自动亮/暗模式 (Auto Light & Dark Mode)**。它提供多种风格选项：优雅、奢华、柔和，并集合了一系列实用功能，带来流畅直观的用户体验。

---

## **主要功能 / 主题风格**

- **新拟态 (Neumorphism)**：柔和且优雅的按钮与卡片。  
- **玻璃拟态 (Glassmorphism)**：带有轻度模糊效果的透明面板，外观平滑。  
- **3D 玻璃 (Glass 3D)**：为卡片与面板增加景深，呈现现代感。  
- **暗黑玻璃 (Glass Dark)**：玻璃拟态的暗色版本，观感舒适护眼。  
- **新粗野主义 (Neo-Brutalism)**：粗体排版与纯色填充，突出关键元素。  
- **极简 UI (Simple UI)**：极简布局，专注于内容，易于导航。  
- **霓虹 UI (Neon UI)**：带有柔和发光效果的交互元素。  
- **水晶玻璃 (Crystal Glass)**：透明的水晶状面板，带有柔和的光线反射。  
- **RGB 强调色 (RGB Accent)**：细腻的 RGB 强调色，突出交互元素。

## 安装

1. **下载软件包**：

   - OpenWrt (IPK):
     ```bash
     opkg install luci-theme-luxe*.ipk
     ```
   - SNAPSHOT (APK):
     ```bash
     apk add luci-theme-luxe*.apk
     ```

2. **启用主题**：

   - 前往 LuCI → System → System → Language and Style。  
   - 从 Design Theme 下拉菜单中选择 **Luxe**。

3. 完成！主题现已激活。
